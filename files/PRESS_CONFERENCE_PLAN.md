# 赛后新闻发布会设计方案

> 版本：v1.0
> 创建日期：2026-02-15
> 状态：待实现

---

## 1. 定位

在比赛结果 (`results`) 之后，新增 **`press`** 阶段。模拟真实记者会，3-5 位随机记者轮流提问。

---

## 2. 核心流程

```
results (排名+解说)
    ↓ [点击"赛后采访"或"跳过"]
press (3-5轮问答)
    ↓
close (应用属性变化 → 返回)
```

---

## 3. 记者系统

### 3.1 媒体类型

| 媒体 | 风格 | 概率 |
|------|------|------|
| ISU 官方时报 | 官方、专业 | 必出 |
| 体育电视台 | 娱乐、流量 | 40% |
| 专业花滑杂志 | 技术分析 | 40% |
| 娱乐周刊 | 八卦、场外 | 30% |
| 当地媒体 | 友好、支持 | 30% |

每次随机抽取 3-4 位记者。

### 3.2 记者数据结构

```typescript
interface PressReporter {
  id: string;
  name: string;
  media: 'isu' | 'tv' | 'magazine' | 'entertainment' | 'local';
  mediaName: string;
}
```

---

## 4. 问题生成逻辑

### 4.1 基础问题 (必选)

根据比赛结果决定：

| 比赛结果 | 问题类型 |
|----------|----------|
| 夺冠 (rank === 1) | "首次夺冠感受" / "未来目标" / "职业生涯意义" |
| 失误 (hasFall) | "失误原因" / "如何调整心态" / "是否压力过大" |
| 普通 | "比赛感受" / "表现评价" |

### 4.2 属性相关 (随机 1-2 个)

```
- TEC > ART + 10: 技术类问题 ("跳跃训练计划", "技术突破")
- ART > TEC + 10: 艺术类问题 ("音乐选择", "表现力")
- 隐藏属性相关 (随机):
  - 心态 < 40: "如何应对紧张"
  - 压力 > 60: "外界压力看法"
  - 舆论 < 30: "负面报道回应"
```

### 4.3 媒体专属 (随机)

```
- 娱乐周刊: "退役计划" / "感情生活" / "商业代言"
- 花滑杂志: "动作难度" / "技术细节"
- 体育 TV: "冠军感受" / "下一个目标"
```

## 5. 回答机制

### 5.1 选项结构

每个问题 3 个选项，不同倾向产生不同效果：

```typescript
interface PressAnswer {
  text: string;           // 回答文本
  tone: 'confident' | 'humble' | 'honest' | 'aggressive';
  effects: {
    mental?: number;
    stress?: number;
    public?: number;
    fame?: number;
  };
}
```

### 5.2 效果表

| 倾向 | 心态 | 压力 | 舆论 | 适用场景 |
|------|------|------|------|----------|
| 自信/强势 | +10~15 | 0 | -5~0 | 夺冠后 |
| 谦逊/温和 | +0~5 | 0 | +5~10 | 任何时候 |
| 卖惨/坦诚 | +5~10 | -10~15 | +0~5 | 失误后/高压力 |
| 狂妄* | +20 | 0 | -15 | 心态 > 80 |
| 甩锅* | -5 | +5 | -10 | 舆论 < 30 |

*带 * 的选项需要特定条件才出现

## 6. UI 设计

### 6.1 布局

```
┌─────────────────────────────────────────────────────────────┐
│  [闪光灯动画效果 - 随机闪烁 📷📷📷]                        │
├─────────────────────────────────────────────────────────────┤
│  ┌──────────┐                           ┌───────────────┐ │
│  │ 📸 ISU   │                           │  💬 第 2/4 轮 │ │
│  │ 记者A    │                           │               │ │
│  └──────────┘                           │  "首次夺冠    │ │
│  ┌──────────┐     ┌──────────┐         │  感受如何？"  │ │
│  │ 📺 体育  │ ←── │ 🎤 记者B  │         │               │ │
│  │ 记者B    │     │ "xxx"     │         └───────────────┘ │
│  └──────────┘     └──────────┘                              │
│  ┌──────────┐     ┌──────────┐         ┌───────────────┐   │
│  │ 📰 杂志  │     │ 聚光灯    │         │ [自信回答]   │   │
│  │ 记者C    │     │ 区域      │         │ [谦逊回答]   │   │
│  └──────────┘     └──────────┘         │ [坦诚回答]   │   │
│                                         └───────────────┘   │
│  [跳过采访]  ←──────────────────────────────────────────    │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 视觉风格

- **背景**：深色 (slate-950)，体现正式感
- **闪光灯**：随机闪烁的相机图标 📷
- **聚光灯**：问题区域高亮，周围暗淡
- **记者区**：左侧显示记者卡片，当前提问者高亮 + 麦克风图标
- **问题区**：中央显示当前记者 + 问题文本
- **回答区**：下方 3 个选项按钮，显示倾向图标

### 6.3 交互

- 点击回答选项 → 显示效果 (+10 心态 等) → 1秒后切换下一题
- "跳过采访" 按钮 → 直接关闭，应用已回答问题的效果

## 7. 隐藏属性

### 7.1 新增字段

```typescript
interface Skater {
  // ... existing fields
  mental: number;    // 心态: 0-100
  stress: number;    // 压力: 0-100
  public: number;    // 舆论: 0-100
}
```

### 7.2 初始值

```
mental: 60  (正常)
stress: 30  (轻松)
public: 50  (中立)
```

### 7.3 变化规则

| 事件 | 心态 | 压力 | 舆论 |
|------|------|------|------|
| 发布会"自信" | +10~15 | 0 | -5~0 |
| 发布会"谦逊" | +0~5 | 0 | +5~10 |
| 发布会"坦诚" | +5~10 | -10~15 | +0~5 |
| 比赛夺冠 | +15 | 0 | +20 |
| 比赛失误 | -10 | +10 | -5 |
| 训练过度 (sta < 20) | -5 | +5 | 0 |
