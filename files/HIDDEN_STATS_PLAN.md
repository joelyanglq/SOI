# 隐藏属性设计方案

> 状态：待讨论
> 创建日期：2026-02-15

---

## 核心理念

每个隐藏属性对应**一个独特的游戏体验**，属性之间**场景完全分离**，避免重叠。

---

## 方案概述

| 隐藏属性 | 独特体验 | 核心作用 |
|----------|----------|----------|
| **心态** | 比赛不确定性 | 比赛结果不完全由属性决定 |
| **压力** | 训练策略权衡 | 避免无脑堆训练 |
| **舆论** | 经济博弈 | 赞助谈判的隐性筹码 |

---

## 1. 心态 (Mental)

### 定位

只作用于**比赛**，影响比赛得分的随机性。

### 核心问题

属性 100 分就一定拿冠军吗？

### 解决方案

```
比赛最终得分 = calculateActionScore(...) × 心态系数
```

| 心态区间 | 心态系数 | 效果 |
|----------|----------|------|
| 巅峰 (90-100) | 1.1x | 稳定发挥，GOE 额外 +1 |
| 正常 (40-89) | 1.0x | 正常发挥 |
| 紧绷 (20-39) | 0.85x | 首个动作可能失误 |
| 崩溃 (0-19) | 0.7x | 连续失误，可能放弃比赛 |

### 心态变化规则

| 事件 | 心态变化 |
|------|----------|
| 首次参加奥运/世锦赛 | -20 |
| 连续 3 个月参赛不休息 | -5 |
| 训练过度 (sta < 20) | -5 |
| 比赛夺冠 | +15 |
| 比赛失误 | -10 |
| 发布会"自信" | +10 |
| 发布会"卖惨" | +5 |

### 与现有模块结合

- `scoring.ts`：计算最终得分时乘以心态系数
- 不修改 GOE 计算公式，保持原逻辑

---

## 2. 压力 (Stress)

### 定位

只作用于**训练**，影响训练效率。

### 核心问题

无脑堆 7 个训练不行了吗？

### 解决方案

```
实际训练效率 = baseEfficiency × (1 - stress / 150)
```

| 压力区间 | 效率系数 | 效果 |
|----------|----------|------|
| 轻松 (0-30) | 1.0x | 正常成长 |
| 适中 (31-60) | 0.8x | 效率下降 |
| 紧张 (61-80) | 0.6x | 明显受限 |
| 崩溃 (81-100) | 0.4x | 属性有概率下降 |

### 压力变化规则（每月）

| 训练槽位数 | 压力变化 |
|------------|----------|
| 7 个训练 | +25 |
| 6 个训练 | +15 |
| 5 个训练 | +5 |
| 4 个及以下 | -10 |

| 其他事件 | 压力变化 |
|----------|----------|
| 参加比赛 | +10 |
| 休息任务 | -20 |
| 负面随机事件 | +15 |
| 发布会"卖惨" | -15 |

### 特殊机制

- 压力 > 80：UI 显示 burnout 警告
- 压力 = 100：进入 burnout 状态，属性有 30% 概率下降 1 点
- 压力 = 0：训练效率额外 +10%

### 与现有模块结合

- `training.ts`：计算 gains 时乘以效率系数
- `useGameState.ts`：每月更新压力值，检查 burnout

---

## 3. 舆论 (Public Perception)

### 定位

只作用于**经济**，影响赞助质量和谈判空间。

### 核心问题

赞助谈判只是一锤子买卖？

### 解决方案

```
赞助质量 = 基础金额 × (1 + 舆论 / 100)
```

| 舆论区间 | 效果 |
|----------|------|
| 狂热 (80-100) | 品牌主动签约，赞助+30% |
| 正面 (50-79) | 正常赞助 |
| 中立 (20-49) | 报道平淡 |
| 负面 (0-19) | 赞助-20%，丑闻曝光 |

### 舆论变化规则

| 事件 | 舆论变化 |
|------|----------|
| 比赛夺冠 | +20 |
| 比赛失误 | -5 |
| 正面报道事件 | +10 |
| 负面报道事件 | -15 |
| 发布会"狂妄" | +10 |
| 发布会"谦逊" | +5 |
| 发布会"甩锅" | -10 |

### 与现有模块结合

- `economy.ts`：
  - 生成赞助时，舆论影响品牌层级出现概率
  - 正面舆论：global/brand 品牌出现概率 +30%
  - 负面舆论：local 品牌出现概率 +50%
- 续约时，舆论决定是否提供"优惠"
- 舆论 < 20：赞助商有 10% 概率提前解约

## 属性间关系

```
┌─────────────────────────────────────────────────────┐
│           隐藏属性与现有模块                         │
├─────────────────────────────────────────────────────┤
│                                                     │
│   PlayerAttributes (5维)                            │
│         ↓ 衍生计算                                  │
│   TEC / ART                                        │
│         ↓                                          │
│   ┌─────────────┐    ┌─────────────┐              │
│   │ 比赛得分    │    │ 训练效果    │              │
│   │ × 心态系数  │    │ × 效率系数  │              │
│   └─────────────┘    └─────────────┘              │
│         ↓                      ↓                    │
│   ┌─────────────┐    ┌─────────────┐              │
│   │ 世界排名    │    │ 属性成长    │              │
│   └─────────────┘    └─────────────┘              │
│         ↓                                            │
│   ┌─────────────────────────────────────┐          │
│   │ 舆论 ←──────────────────────────→ 经济         │
│   └─────────────────────────────────────┘          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 属性间化学反应

虽然属性场景分离，但会产生间接互动：

```
压力高 → 心态下降 → 比赛失误 → 舆论负面 → 赞助减少
    ↑                                      ↓
    └──────── 冰迷失望 (暂不加入) ──────────┘
```

---

## 不加入的属性及原因

| 属性 | 原因 |
|------|------|
| 冰迷忠诚 | 和 fame 名望重叠，且对核心循环影响小 |
| 商业价值 | 可合并到舆论中，不需要单独属性 |
| 大赛经验 | 属于"解锁"概念，不是持续状态属性 |

---

## 实现优先级

| 阶段 | 属性 | 工作量 | 效果 |
|------|------|--------|------|
| 1 | 心态 | 小 | 比赛不再只看属性 |
| 2 | 压力 | 中 | 训练需要策略思考 |
| 3 | 舆论 | 中 | 经济系统更有趣 |
